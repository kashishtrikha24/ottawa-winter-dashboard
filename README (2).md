# Ottawa Winter 2025/2026 — Satellite Viewer

A Streamlit app that displays Sentinel-2 true-color satellite images of the
Ottawa region across five windows of Winter 2025/2026, along with a
cloud-cover summary for each window.

The imagery and CSV are generated by the companion notebook,
`Ottawa_Winter2026_MultiImage.ipynb`, which pulls data from Google Earth
Engine. This app itself does **not** call Earth Engine — it just reads the
PNGs and CSV that the notebook exports.

## How the data was made

For each date window, the notebook:

1. Queries Sentinel-2 Surface Reflectance (`COPERNICUS/S2_SR_HARMONIZED`)
   scenes over the Ottawa bounding box.
2. Picks the scene with the lowest `CLOUDY_PIXEL_PERCENTAGE`.
3. If that scene is still cloudier than 50%, it swaps in a **median
   composite** across all scenes in the window instead — median compositing
   cancels out clouds because at each pixel, cloud pixels tend to be
   brighter outliers that a median (rather than a mean) discards.
4. Records the real capture date (or the window's date range, for
   composites) and the cloud-cover percentage into
   `ottawa_winter_2026_cloud_summary.csv`.

## Running the app

1. Make sure all the files listed above are in the same folder.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the app:
   ```bash
   streamlit run stream.py
   ```
4. Your browser will open to `http://localhost:8501`.

## Features

- **Grid view** — all five windows at once, each captioned with its date,
  cloud cover, and whether it's a single scene or composite.
- **Single window view** — pick one window from a dropdown to see it larger.
- **Sortable, highlightable summary table** — sort by cloud cover, and set a
  threshold to visually flag the cloudiest windows.
- Summary metrics: average cloud cover across all windows and how many
  windows needed a composite fallback.

## Regenerating the data

To pull fresh imagery (e.g., different date windows, a different threshold,
or a later run of the season), open `Ottawa_Winter2026_MultiImage.ipynb` in
Google Colab, edit the `DATE_WINDOWS` list and/or `CLOUD_FALLBACK_THRESHOLD`
in Step 3, and run all cells. Step 8 downloads the updated PNGs and CSV,
which you can then drop into this app's folder in place of the old ones.
